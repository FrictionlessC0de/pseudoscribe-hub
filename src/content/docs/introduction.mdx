## What is pseudocode?

Pseudocode is a way to describe an algorithm using plain language and a little structure. It lets you focus on what your program should do, without getting caught up in the syntax of a programming language.

No strict rules. No compiler errors. Just you, your logic, and a plan.

<Callout title="A way to think, not a language to learn">
  Think of pseudocode as the bridge between an idea and working code.
</Callout>
